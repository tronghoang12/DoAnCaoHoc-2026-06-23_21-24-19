# Gemini Project: My project

## Project Overview

This is a Unity project created with Unity version 6000.4.10f1. 

The project utilizes the Universal Render Pipeline (URP) and includes packages for the Input System, AI Navigation, Visual Scripting, and others. The main scene is `SampleScene.unity`.

The project contains C# scripts for gameplay logic. The `Check.cs` script includes functionality to search for keywords and manipulate camera and GameObjects, suggesting some form of interactive or narrative elements.

## Building and Running

1.  **Open in Unity Hub:** Open this project using Unity Hub.
2.  **Select Unity Version:** Ensure you have Unity Editor version **6000.4.10f1** installed. If not, you will be prompted to install it through Unity Hub.
3.  **Open the Scene:** Once the project is open in the Unity Editor, locate the `SampleScene` in the `Assets/Scenes` folder and open it.
4.  **Run the project:** Press the "Play" button in the Unity Editor to run the scene.

## Development Conventions

*   The project uses C# for scripting.
*   Scripts are organized in the `Assets/Script` folder.
*   The project is set up with a `.vsconfig` file, indicating that Visual Studio is the preferred IDE.
*   Based on the existing `Check.cs` script, there is some Vietnamese language used in comments and debug logs.
*   The code interacts with GameObjects by finding and manipulating them (e.g., `_mainCamera.SetActive(false)`).
